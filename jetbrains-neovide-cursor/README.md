# Lune Glide — IntelliJ IDEA

**流光 · 让光标如流光般滑行。**

Neovide 风格的四角弹簧光标动画，支持柔和拖尾、多光标和可调节动画。停止移动后恢复原生光标。

## 安装

1. 从 [GitHub Releases](https://github.com/BowlofThinSoup/Lune-Glide/releases) 下载 `lune-glide-jetbrains-0.1.3.zip`。
2. 在 **Settings → Plugins → Install Plugin from Disk…** 中选择 ZIP，无需解压。
3. 按提示重启 IDEA。

适用于 **IntelliJ IDEA 2026.2.x（build 262.*）**，已在 2026.2.3 验证。旧版本升级后若仍显示 Neovide Cursor，请确认已安装 0.1.3 并重启。

## 使用

打开 **Settings → Editor → Lune Glide**，调整动画速度、拖尾强度、输入动画和方块光标；开启 **Reduce motion** 可恢复原生光标。

通过 **Lune Glide: Toggle Animation** 随时开关。插件可正常禁用或卸载。
